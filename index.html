Диагностика: API, графики, активность 24ч

Отдельная страница для проверки, что именно не работает в основном приложении. Основной index.html пока не трогаем. На скриншоте ошибка была "Failed to fetch" — это либо блокировка сети в окне предпросмотра файла в приложении Claude, либо блок конкретного домена. Ниже — несколько независимых тестов, чтобы понять, что именно работает.
0. Базовая проверка сети (без криптобирж) ⏳
Простой запрос к нейтральному публичному API. Если этот тест тоже падает — проблема не в CoinGecko, а в том, что среда предпросмотра вообще не даёт делать сетевые запросы (тогда всё заработает только после того, как вы откроете файл на реальном хостинге / в браузере, а не во встроенном просмотрщике).
GET https://jsonplaceholder.typicode.com/todos/1
—
1. CoinGecko: цена TON/USDT в ₽ ⏳
Тот же запрос, что использует основное приложение для живых цен.
GET https://api.coingecko.com/api/v3/simple/price?ids=the-open-network,tether&vs_currencies=rub&include_24hr_change=true
—
2. CoinGecko: реальная история цены (график за 24ч) ⏳
Вместо случайно сгенерированных точек — реальные исторические цены TON за последние сутки, отрисованные через Chart.js. Так будет выглядеть настоящий график.
GET https://api.coingecko.com/api/v3/coins/the-open-network/market_chart?vs_currency=rub&days=1
—
3. Binance: сводка за 24ч (запасной источник цен) ⏳
Binance — запасной вариант, если CoinGecko упирается в лимит запросов. Здесь есть объём торгов, но нет разбивки на покупки/продажи.
GET https://api.binance.com/api/v3/ticker/24hr?symbol=TONUSDT
—
4. Binance: реальные "Покупка/Продажа" за 24ч ⏳
CoinGecko не отдаёт разбивку объёма на покупки/продажи. У Binance это можно посчитать по 24 свечкам за час: berём "taker buy quote volume" против общего объёма. Так карточка "Торговая активность" станет настоящей, а не случайной.
GET https://api.binance.com/api/v3/klines?symbol=TONUSDT&interval=1h&limit=24
—
5. STON.fi: цена жетонов TON (UTYA, REDO, tsTON…) ⏳
Самое важное для вас: STON.fi — крупнейшая DEX на TON, и на ней реально торгуются именно ваши мемные жетоны (UTYA, REDO и т.д.), которых нет на CoinGecko/Binance. Без ключа, без официального лимита.
POST https://api.ston.fi/v1/assets/query { search_terms: ["UTYA"] }
—
6. OKX: цена TON ⏳
Ещё один запасной вариант с публичным API без ключа.
GET https://www.okx.com/api/v5/market/ticker?instId=TON-USDT
—
7. Bybit: цена TON ⏳
Публичный API без ключа, высокие лимиты.
GET https://api.bybit.com/v5/market/tickers?category=spot&symbol=TONUSDT
—
8. KuCoin: цена TON ⏳
Публичный API без ключа.
GET https://api.kucoin.com/api/v1/market/stats?symbol=TON-USDT
—
9. CoinCap: цена TON в $ ⏳
Простой бесплатный агрегатор без ключа, отдаёт цену в долларах (для рублей пришлось бы отдельно брать курс USD→RUB).
GET https://api.coincap.io/v2/assets/the-open-network
